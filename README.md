# OopsMCP v1.5.0

OopsMCP — a role-based toolbox with dedicated UI workspaces for 500 capabilities, an MCP endpoint, and a Vercel deployment entry point.

The complete v1.5.0 source bundle is available from the project build artifact. This README initializes the repository so the initial commit and branch exist.
