# OopsMCP Deployment

## Vercel

Import the project and set the Supabase environment variables.

## Supabase

Run `supabase/schema.sql`.

## Endpoint

`https://YOUR_PROJECT.vercel.app/mcp`

## Studio

`https://YOUR_PROJECT.vercel.app/`

## Install

`https://YOUR_PROJECT.vercel.app/install`


### Dedicated tool UI
Each of the 500 registered capabilities is reachable from `/tools/<tool-id>` with a dedicated UI template.
